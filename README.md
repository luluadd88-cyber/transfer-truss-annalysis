# Transfer Truss Structural Analysis (CIV2100)

Author: lamees

This project presents a structural analysis of a transfer truss system for a vertical extension feasibility study.

## Overview
Includes:
- Elastic Analysis (Stiffness Matrix Method)
- Plastic Analysis (Sequential Yielding)
- Parametric Study (Section optimisation)

## How to Run
pip install numpy matplotlib
python src/truss_analysis.py
